# 🕷️ Spider-Man: Brand New Day — Hero Landing Page
## EM DESENVOLVIMENTO 
Projeto de reprodução em alta fidelidade de uma **Hero Section** interativa desenvolvida durante o curso de **Figma com IA da DevHub Educação**. O objetivo principal foi alinhar design visual avançado no Figma com desenvolvimento front-end moderno assistido por Inteligência Artificial.

---

## 📌 Sobre o Projeto

A aplicação consiste na interface principal para o filme *Spider-Man: Brand New Day*. O layout conta com recortes curvos côncavos (*notches*) aplicados via **CSS SVG Masking**, fundo dinâmico em tons de vinho/vermelho com teia, além de comportamentos interativos como efeito de *parallax* suave no personagem e navegação direta ao trailer oficial.

---

## 👨‍💻 Minhas Responsabilidades no Projeto

Este projeto foi construído com suporte de ferramentas de IA, onde atuei diretamente nas seguintes etapas:

* **🎨 Design no Figma:** Criação completa do protótipo visual, composição dos elementos, tipografia e definição das máscaras vetoriais.
* **🤖 Prompt Engineering:** Elaboração de *prompts* estruturados para geração de base de código (HTML/CSS/JS) e ativos visuais.
* **🖼️ Geração de Imagens & Assets:** Extração, recorte e geração dos *assets* gráficos e vetoriais utilizados na interface.
* **🔍 Revisão, Debugging & Correção de Código:** Refatoração manual de layout, ajuste fino de CSS (`mask-image`, `z-index`, *flexbox/grid*), correção de alinhamentos e garantia da paridade com o protótipo.

---

## 🛠️ Tecnologias Utilizadas

### Front-end

* **HTML5:** Estruturação semântica da página.
* **CSS3:**
* Máscaras vetoriais complexas (`mask-image` com SVG).
* Layout flexível (*Flexbox* e *CSS Grid*).
* Variáveis CSS e animações Keyframes.


* **JavaScript (Vanilla):** Efeito Parallax sutil ao mover o cursor e rolagem suave da página.

### Design & IA

* **Figma:** Prototipagem e UI Design.
* **Engenharia de Prompt:** IA Generativa para auxílio no código e ativos gráficos.
